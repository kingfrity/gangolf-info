Datenschutzerklärung für Gangolf

Stand: 25. November 2026

Wer betreibt die Anwendung

Gangolf ist eine private Anwendung der Familie Peßler, Hamburg. Sie wird ausschließlich von Mitgliedern des Haushalts genutzt. Kontakt: moin@pessler.org.

Welche Google-Daten genutzt werden

Nach ausdrücklicher Zustimmung im Google-Anmeldefenster greift die Anwendung auf die Google-Dienste des jeweiligen Nutzers zu: Gmail (Lesen und Entwürfe anlegen), Google Kalender (Termine lesen und eintragen), Google Drive, Docs und Tabellen (Dokumente lesen und anlegen) sowie Kontakte (lesen). Genutzt werden nur die Dienste, denen der Nutzer zugestimmt hat.

Wofür

Ausschließlich, um dem Nutzer selbst zu helfen: Termine und Trainingseinheiten im eigenen Kalender verwalten, E-Mails zusammenfassen und Antwortentwürfe vorbereiten, Dokumente finden und ablegen. E-Mails werden nie ohne Bestätigung des Nutzers versendet.

Speicherung und Weitergabe

Die Daten werden auf einem privaten Server im Haushalt verarbeitet und gespeichert. Sie werden nicht verkauft, nicht für Werbung genutzt und nicht an Dritte weitergegeben. Zur Verarbeitung von Texten kann ein KI-Sprachmodell (Anthropic Claude) eingesetzt werden. Dabei werden nur die für die jeweilige Aufgabe nötigen Inhalte übermittelt, nicht zum Training freigegeben und nicht dauerhaft beim Anbieter gespeichert.

Die Nutzung von Daten aus Google-APIs hält sich an die Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Löschen und Widerruf

Der Zugriff lässt sich jederzeit unter myaccount.google.com/permissions widerrufen. Auf Wunsch werden gespeicherte Daten gelöscht, eine kurze Nachricht an die Kontaktadresse genügt.

English summary: Gangolf is a private, self-hosted app used only by the Peßler household. Google user data (Gmail, Calendar, Drive, Docs, Sheets, Contacts) is accessed only with the user's consent, used solely to assist that user, stored on a private home server, never sold, never used for advertising and never shared with third parties. Use of data from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
